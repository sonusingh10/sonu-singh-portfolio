# React Bits components used

These TypeScript + Tailwind components were copied from the official React Bits
registry on 11 October 2026:

- [Blur Text](https://github.com/DavidHDev/react-bits/tree/main/src/ts-tailwind/TextAnimations/BlurText)
- [Magnet](https://github.com/DavidHDev/react-bits/tree/main/src/ts-tailwind/Animations/Magnet)
- [Spotlight Card](https://github.com/DavidHDev/react-bits/tree/main/src/ts-tailwind/Components/SpotlightCard)

Blur Text and Spotlight Card are used as small progressive enhancements. Magnet is used
for the single hero CTA, with its listener disabled for touch and reduced-motion users.
The site keeps all meaningful copy in server-rendered HTML. The upstream license and
its Commons Clause are included alongside the copied source.
